# image-store-for-cordoval

Public asset host for Cordoval product logos and website images.

## Paths

- `logos/<product-slug>.svg` — canonical SVG marks
- `logos/<product-slug>.png` — raster previews
- `ads/store-footer-ad.png` — shared Cordoval store footer banner (also `ads/store-footer-ad.svg`)

## URLs

Raw: `https://raw.githubusercontent.com/Gitkierenoffical/image-store-for-cordoval/main/<path>`
jsDelivr: `https://cdn.jsdelivr.net/gh/Gitkierenoffical/image-store-for-cordoval@main/<path>`

Not for social post graphics.
